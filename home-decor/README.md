# 装修实验室（2.5D 原型 0.1.5）

选户型 → 硬装 → 软装，一步步搭出理想家。当前是可玩原型：一个 6×6 一居室、Canvas 2D 等距渲染。

## 原型能力

- **硬装阶段**：地板（原木 / 浅灰 / 水磨石）、墙面（奶油 / 鼠尾草 / 灰蓝）、灯光（暖光 / 自然光 / 冷光），实时预览。
- **软装阶段**：12 件家具与挂饰——沙发、床、地毯、茶几、书架、电视柜、单椅、边几、绿植、落地灯、挂画、窗帘。
- **操作**：点家具再点地面放置；挂画和窗帘点墙面；已放置物件可选中、旋转 90°、移除；支持撤销。目录自动换行展示全部 12 件，选中后画面顶部提示「点地面放置」，空位会高亮；也可以点「放到空位」自动落地。
- **建材市场**：6 个分类、22 件材料/家具/工具，带统一风格的矢量产品示意图；点开可看材质、环保等级、适用空间和选购提示；用虚拟预算购买，人字拼地板、微水泥墙面、暖光氛围灯购买后会解锁到硬装。
- **商品图**：22 张 SVG 示意图放在 `dist/assets/market/`，非真实商品照片。
- **完成**：生成 900×1200 等距明信片，可保存相册、分享图片、发布笔记。
- **保存**：材质、家具位置、声音开关和进度保存在容器 Storage，重开可继续。
- **声音**：音效默认开（选择、放置、旋转、移除、撤销、换材质、完工）；背景音乐默认关，是萨蒂《裸体歌舞》三拍子改编的舒缓循环，Web Audio 合成。
- **渲染**：全部由 Canvas 2D 绘制，不加载外部图片；明信片复用同一套绘制逻辑。

## 操作

- 选「奶油一居室」→ 开始装修。
- 硬装：点材质色块实时预览 → 下一步。
- 软装：点目录里的家具 → 点地面放置；「旋转」调整朝向；点已放置家具可移除。
- 放满 3 件以上可「完成装修」。

## 已知限制

- 原型只开放一个户型；两居室占位未实现。
- 只有一套奶油/原木色系家具，尚未做风格包与预算/订单玩法。
- 没有评分（平台无 AI 审美能力），完成页展示家具数量与材质组合。
- 家具为程序化简化造型，不是精细美术资产；正式版建议补一套统一风格的 SVG/位图素材。
- 未做音频；拖拽目前是「点选 + 点放」，不是连续拖拽。
- 建材市场用虚拟预算，不涉及真实支付；除 3 个解锁材质外，其余购买记录只作为清单和科普档案，不影响摆放。
- 未上传平台，尚未在创服模拟器和真机验证。

## 下一步建议

1. 增加第二个户型（两居室），验证不同房间尺寸的适配。
2. 增加风格包（奶油 / 原木 / 中古），家具颜色与材质联动。
3. 加入预算或订单约束，形成玩法。
4. 连续拖拽 + 家具贴墙吸附。
