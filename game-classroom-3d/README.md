# 课堂偷吃大作战 3D

固定机位的 3D 教室偷吃游戏：老师背对黑板写字时按住偷吃，转身前把嘴里的零食咽下去。Three.js 低模场景，老师有转身、写字与表情变化，第一人称手部完成取饼、咬、咀嚼与掉屑。

## 玩法

- 课表共六节：语文、数学、英语、物理、化学、期末，拿到 1 星解锁下一节。
- 点一节课开始，老师面向黑板写字，按住「吃」积累进度。
- 老师停笔后可能真转身，也可能只是假停笔（物理/化学/期末）；假动作会转一部分就回去。
- 一个零食吃完进入约 0.9 秒咀嚼，老师转身完成时嘴里还有东西就会被抓。
- 被抓扣一条命；按剩余生命比例评星：满血 3 星、掉一半 2 星、残血 1 星，六节课共 18 颗星。
- 结束后生成 900×1200 成绩卡，可保存 / 分享 / 发布笔记。

## 实现

- `vendor/three.min.js`：Three.js r128（WebGL1，MIT，压缩后约 150 KB）。
- `engine.js`：与 2.5D 版相同的状态机。
- `app.js`：
  - 教室：地板、三面墙、CanvasTexture 黑板（语文 / 数学 / 英语三种板书）、挂钟、海报、讲台、课桌、黑板擦与粉笔。
  - 老师形象按课程切换：语文老师长发、赤陶色上衣、不戴眼镜；数学老师短发、蓝衬衫、眼镜；英语老师发髻、米色上衣配绿色开衫马甲、眼镜。
  - 老师：低模人形，头发、五官、眼镜（含镜腿）、领口、纽扣、腰带、锥形裤腿与圆头鞋；两段式手臂（袖口、前臂、手掌、四指、拇指），写字时肩部扫动、肘部起落、腕部轻摆，粉笔只在写字时出现。
  - 吃东西：手从画面下缘抬起，饼干随进度倾斜，吃到 72% 换成带缺口的饼干，咀嚼时咬过的饼干停在嘴边、手指开合、碎屑掉落。
  - 音效：粉笔、转身提示、被抓、吃到、胜负；背景音乐为原创五声音阶摇篮曲（C–Am–F–G 慢速分解和弦），全部 Web Audio 合成。
  - 关卡：`engine.js` 的 `LEVELS` 配置六节课的目标、生命、写字/盯人区间、停笔预告、假停笔与假动作概率；课表界面按星级解锁。
  - 停笔预告：写字结束先进入 `pausing`，粉笔声停止、手臂定格，再决定转身。预告时长：语文 0.9 / 数学 0.3 / 英语 0.7 / 物理 0.45 / 化学 0.4 / 期末 0.3 秒。
  - 假停笔：物理、化学、期末在停笔后有概率只是停一下又继续写（`resume` 事件），不是每次停笔都会转身。
  - 假动作：英语、化学、期末每次真停笔后有概率只转一部分再转回去（`faking`，幅度 0.5–0.8 圈，0.9 秒），期间安全。
  - 星级按剩余生命比例计算：三命关 3/2/1 星，两命关满血 3 星、剩 1 命 2 星，一命关通关即 3 星。
  - 星级：通关时剩余生命 3/2/1 对应 3/2/1 星，按关卡保存在 `classroomsnack3d.v1.best` 的 `levels` 字段。
  - 声音开关：音效与背景音乐默认开，选择保存在同一记录的 `sound` 字段。
  - 性能：800×600、DPR 上限 1.5、无阴影；WebGL 不可用时禁用开始并给出说明。

- 0.1.1：老师补全头发、五官、眼镜、领口、四肢和鞋子；吃东西改为握饼干动作。

## 已知限制

- 固定机位，不能自由移动；只有一个教室、一个老师，无难度与道具。
- 人物是程序化低模，没有骨骼动画与 glTF 模型；写字、转身、咀嚼都是插值近似。
- 第一人称嘴部因遮挡画面未启用，吃东西主要靠手、饼干与碎屑表达。
- 真机帧率、发热与 WebGL 兼容性尚未实测，需在创服平台模拟器、Android 与 iOS 真机验证。
